# Repository checklist

The package includes:

- Server source and eight MCP tools.
- Shared workspace path checks.
- Input schemas and safe operation errors.
- Locked npm dependencies and TypeScript configuration.
- PM2 configuration and environment example.
- Windows and Claude Desktop setup instructions.
- Four initial handoff files and generic task data.
- Tool reference, design report, and automated test results.
- Windows/Linux CI configuration.

Before uploading to GitHub, exclude `.env`, `node_modules`, credentials and private files. Commit `package-lock.json`. Make sure the instructor can access the repository.

This documentation package does not include session recordings or live presentation preparation. It does not claim those activities were completed.
